# Трекер CSE / Major Express (Chrome Extension)

Компактное расширение для браузера Google Chrome (**Manifest V3**) — мини-виджет 380 px для отслеживания отправлений курьерских служб **CSE (Курьер Сервис Экспресс)** и **Major Express**: поиск по трек-номеру, полный текст накладной с сайта «как есть», история из 50 записей, ручной статус «Выдано / Не выдано» и встроенный архив.

**Текущая версия:** 1.1.0 (по `manifest.json`).

## 🚀 Возможности

### Поиск по трек-номеру
- Выбор перевозчика переключателем **CSE / MAJOR** — выбор запоминается.
- Поле ввода с кнопками: **✕** очистить, **📋** вставить из буфера обмена.
- Запуск — кнопкой **«Найти»** или клавишей **Enter**.
- Последний использованный номер автоматически подставляется при следующем открытии виджета.
- Результат открывается в карточке: тег перевозчика, трек-номер, полный текст накладной, время последней проверки, ссылка на официальную страницу отслеживания.

### Полная информация с сайта «как есть» (без потерь)
- Никакого «угадывания» статуса по отдельным словам: текст переносится **целиком и без искажений**.
- В накладной сохраняются: маршрут (откуда/куда), даты и время чекпоинтов, имена назначенных курьеров, терминалы, склады и вся цепочка отметок.
- Обрезаются только служебные «крайние» части: меню/шапка страницы (до заголовка «Накладная № / Откуда: / Статус доставки / Результат отслеживания») и юридический футер (копирайт, политика конфиденциальности) — если он дальше 80 символов от начала.
- Пустые строки нормализуются (не более одной пустой строки подряд), детали событий не теряются.

### Разворачиваемая история
- По умолчанию блок текста **свёрнут** — компактные 3–4 строки.
- Кнопка **«Развернуть всю историю ▼»** открывает полный текст строчка за строчкой; **«Свернуть историю ▲»** возвращает к компактному виду.

### Пользовательский статус «Выдано / Не выдано»
- Каждая новая посылка по умолчанию — **«Не выдано»**.
- В карточке результата — кнопка **«✓ Отметить как выдано»** (и обратно — **«Вернуть в активные»**).
- Статус виден бейджем с цветной точкой: 🟢 **Выдано** / 🟡 **Не выдано**.
- При повторном поиске того же номера **ручной статус сохраняется** — он не сбрасывается обновлением данных.

### Вкладка «Мои посылки» с фильтрами
- Переключение **«Активные (Не выдано)»** и **«Архив (Выдано)»** с живыми счётчиками.
- Карточка отправления: тег перевозчика, номер, бейдж статуса, превью из первых 3 строк накладной, время проверки.
- Действия по карточке:
  - **«Выдано» / «В активные»** — перенос между списками;
  - **🔄** — обновить данные с сайта (переходит на вкладку поиска и выполняет запрос);
  - **📋** — скопировать трек-номер;
  - **🗑️** — удалить запись навсегда.
- Клик по карточке открывает её в детальном виде на вкладке «Поиск».
- Кнопка **«Очистить текущий список»** — массовое удаление только открытого фильтра (с подтверждением): из «Архива» или из «Активных», второй список не затрагивается.

### Встроенный Архив
- Отметка «Выдано» мгновенно переносит посылку во вкладку **«Архив»**, не засоряя активный список.
- Из архива посылку можно в один клик вернуть обратно или удалить.

### Надёжность
- Лимит ожидания ответа сайта — **28 секунд**; по таймауту показывается понятное сообщение («сайт медленно отвечает или требует капчу») с кнопкой **«Повторить»**.
- Фоновые вкладки закрываются **гарантированно** — в любом исходе (успех, ошибка, таймаут): утечек вкладок и памяти нет.
- Защита от повторных нажатий: во время поиска кнопка «Найти» заблокирована, показывается спиннер и статус «Загрузка...».
- Уведомления-тосты о каждом действии (копирование, перенос, удаление, вставка).

## ⚙️ Как устроен поиск

1. По номеру и перевозчику формируется официальный URL:
   - **CSE** — `https://www.cse.ru/mow/track/?numbers=<номер>`;
   - **Major** — `https://www.major-express.ru/useful-services/track/?type=1&tracking-number=<номер>`.
2. URL открывается в **фоновой (неактивной) вкладке** — она не мешает работе.
3. После статуса загрузки `complete` выдерживается **2.4 секунды** (время на дозагрузку JS-контента страницы).
4. Через `chrome.scripting.executeScript` читается `document.body.innerText` — текст страницы без разметки.
5. Текст очищается от шапки и футера, нормализуются пустые строки.
6. Вкладка закрывается, результат отображается в карточке и сохраняется в историю.
7. При любой ошибке или по истечении 28 секунд вкладка тоже закрывается, пользователю показывается ошибка.

Вся логика — в `popup.js`; фоновые страницы и service worker не используются.

## 📄 Формат отображаемых данных

Запись истории (объект в хранилище):

| Поле | Тип | Назначение |
|---|---|---|
| `carrier` | строка | перевозчик: `cse` или `major` |
| `num` | строка | трек-номер накладной |
| `trackingContent` | строка | очищенный текст накладной (для показа в UI) |
| `rawText` | строка | сырой текст страницы целиком (для отладки, кнопка «dbg») |
| `isDelivered` | логический | ручной статус: `true` — выдано (архив), `false` — не выдано (активные) |
| `checkedAt` | число | время последней проверки (timestamp), отображается как «только что / N мин назад / Сегодня, ЧЧ:ММ / ДД.ММ, ЧЧ:ММ» |

Идентификатор записи — пара **перевозчик + номер** (номер сравнивается без учёта регистра): повторный поиск обновляет текст и время, **сохраняя** ручной статус. История ограничена **50 записями** (самые старые удаляются автоматически).

## 🖱️ Интерфейс и управление

**Вкладка «Поиск»**
- Переключатель перевозчика `CSE | MAJOR`
- Поле номера: ✕ очистить, 📋 вставить, **Enter** — поиск
- Карточка результата: бейдж перевозчика, номер, бейдж статуса, сворачиваемый текст, «Проверено: …», ссылка на сайт перевозчика, кнопка смены статуса, кнопка копирования номера
- Кнопка **dbg** — показать/скрыть сырой текст страницы (полный `rawText`)
- При ошибке — баннер «Ошибка проверки» с описанием и кнопкой «Повторить»

**Вкладка «Мои посылки»**
- Фильтры `Активные (N) | Архив (N)` со счётчиками
- Список карточек с превью и действиями (см. выше)
- Кнопка «Очистить текущий список» (с подтверждением)

## 💾 Хранение данных

Всё хранится локально в `chrome.storage.local` (ключи):

| Ключ | Содержимое |
|---|---|
| `carrier` | последний выбранный перевозчик |
| `num` | последний введённый трек-номер |
| `parcel_history` | массив записей истории (до 50, включая `rawText` каждой записи) |

Данные не отправляются на серверы разработчика: передачи информации на сторонние ресурсы, кроме посещения официальных сайтов перевозчиков, нет.

## 📦 Установка и обновление в Chrome

**Установка (первый раз):**
1. Откройте `chrome://extensions/`.
2. Включите **«Режим разработчика»** (переключатель справа сверху).
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку проекта.

**Обновление после правок:**
1. Откройте `chrome://extensions/`.
2. Найдите карточку **«Трекер CSE / Major»**.
3. Нажмите кнопку **«Обновить»** (круговая стрелка) — при необходимости сначала «Перезагрузить».
4. Готово: при поиске трека отобразится полная официальная информация с кнопкой разворачивания истории.

## 🐞 Отладка

- **Кнопка `dbg`** внизу вкладки «Поиск» — показывает сырой текст страницы (`rawText`) как он пришёл с сайта: полезно, если данные не отобразились или отобразились не полностью.
- Консоль ошибок расширения: `chrome://extensions/` → «Фоновый процесс» / «Смотреть» в карточке расширения; popup — правой кнопкой по виджету → «Проверить».
- Если результат пустой, проверьте на сайте перевозчика вручную: возможна капча или анти-бот-защита (расширение об этом сообщает по таймауту).

## ⚠️ Ограничения и известные особенности

- **Капча / анти-бот.** Если сайт CSE или Major требует подтверждение (капча, проверка браузера), чтение вернёт неполный текст или таймаут 28 с. Помогает: открыть сайт перевозчика вручную один раз, пройти проверку и повторить поиск.
- **Зависимость от вёрстки сайта.** Определение начала накладной и футера — по текстовым маркерам («Накладная №», «Откуда:», копирайт и т.п.). Если перевозчик изменит шаблон страницы, границы обрезки могут сместиться; сырой текст всегда доступен по кнопке `dbg`.
- **Лимит истории — 50 записей.** Более старые удаляются автоматически; вместе с каждой записью хранится полный `rawText`, поэтому объём хранилища растёт пропорционально количеству проверок.
- **Статус «Выдано / Не выдано» — пользовательский.** Расширение не определяет выдачу автоматически: статус выставляете только вы вручную и хранится локально.
- **Иконки — растровые PNG** (16/48/128 px), не векторные.
- Расширение работает только с указанными двумя перевозчиками; поддержка других служб не предусмотрена.
